Addons de Fubol

Catalogo curado de addons oficiales, open source y configurables para Stremio/Nuvio. Los scrapers P2P estan marcados: su codigo puede ser abierto, pero el contenido que indexan puede no estar licenciado. La licencia verificar significa que el addon es hosted y no se encontro un repo publico con licencia.

Regla P2P: si usas el debrid nativo de Nuvio (TorBox/Premiumize), configura los scrapers sin API key y en modo P2P. Si el addon resuelve debrid, Nuvio nunca ve el hash.
